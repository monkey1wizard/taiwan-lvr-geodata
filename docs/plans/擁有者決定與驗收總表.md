## 六、已知風險

- 已發布的第一版少了 380,134 個已定位門牌：輸出程式以地址成員原本的鍵對應定位結果，地址池改寫過鍵的門牌因此沒有輸出。基線 `r07-10-20261016b` 依成員原鍵為 3,551,724 列，依地址出現列的鍵為 3,931,858 列。10-20 e10 獨立計算更正成因：漏寫 380,135 個，補區 368,234、改名 10,310、其餘 1,591；另多寫 1 列地址池送候選查核的門牌 `106q3/e_lvr_land_a.csv/27`，淨差 380,134。程式已於 10-18 修正（`7d969c2`）。10-18 擁有者決定第一版不另行更正，由第二版全量重跑（e02）一起補上。
- B 段 期間若上傳了目前的第 2 批，該批文字永久留在帳本，帶入新基線時會有鍵對不上的查詢，需人工處理。

- 第一版 `data/output/` 已使 repo 超過 GitHub 建議的 5 GB，第二版會再加約 10 GB。擁有者已接受。
- 各批次明細欄位的實際差異尚未整理。
- 行政區表換行風險已於 10-14 解除，只有 3 個不受執行檢查的 metadata 檔仍隨平台換行。
