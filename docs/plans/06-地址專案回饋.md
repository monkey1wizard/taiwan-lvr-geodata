# 06 地址專案回饋

修訂日期：2026-10-18。現況與擁有者決定以 [00 主企劃](00-主企劃.md)為準。本文件取代原「地址專案匯入企劃」，原文在 `docs/archive/地址專案匯入企劃.md`。

## 目的

把本專案經新規則核驗的 TGOS 與人工查核座標，整理成地址資料庫專案 `taiwan-address-data` 的補充候選，由擁有者決定是否匯入。本專案不修改地址專案，不切它的 HEAD。

## 前置

- 子企劃 04 的 R10-2 與 V-13 完成。
- 不在 P0 範圍發布或更新地址專案。

## 交接格式

14 欄 CSV，欄名與順序固定，見[地址規則](../地址規則.md)「地址補充交接」。`X` 為經度，`Y` 為緯度。缺少行政代碼時不得編造。

| 結果 | 分類與後續 |
| --- | --- |
| 地址基底中不存在且證據有效 | 新增候選 |
| 地址來源中已存在且座標相同 | 依本次新證據建立補充候選，不重複新增 |
| 地址來源中已存在但有效座標需更新 | 更新候選，保留來源值、候選值與依據 |
| 地址不符、代碼缺失或多解、座標無效或衝突 | 隔離，保留原因 |
