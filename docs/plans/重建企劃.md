## 已確認的範圍與決定

- 第一個新版資料交付須涵蓋全部選定歷史來源、買賣／預售屋／租賃三類，不以單季試跑代替。缺批次及來源列去向必須明確。
- 門牌鍵唯一欄位、函式及匯出名稱為 `building_key`，採用獨立重驗後的現行 v2 規則，規則版本存 metadata。名稱遷移已於 2026-10-12 完成，`building_key_v2` 與 `legacy_building_key` 已移除，不得重新加入 alias、wrapper、雙軌或舊結果 fallback。獨立案例重驗仍待完成。保留無關 CLI 入口及 `validated_roc_to_tx_yyyymm`。不得推斷交易身分、修訂先後、子門牌等價、座標軸或來源權限。
- 新 run 僅從重新核對的原始來源清單、ZIP、地址來源和明確核驗可納入的原始 TGOS 回傳開始。舊衍生資料全數隔離，包括 normalized／converted、地址池／index／state、aliases、TGOS 採用結果、review 裁定、cache、快照、維護包、公開輸出及統計。送查帳本保留防止重送，但不繼承定位。新快照只可在本次重建已驗證階段內重用。
- 使用固定地址來源與版本，先完成離線定位，再人工準備 TGOS 交換檔。`run-full` 目前不執行 TGOS；新版 TGOS 狀態須由相關 R 工作接入 run 目錄。
- 地址補字、同址、離線定位及 TGOS 採用細節以[地址規則](../地址規則.md)為準。內部識別、證據與快照關聯以[資料契約](../資料契約.md)為準。
- 新版輸出規格於 2026-10-11 至 12 由擁有者確認，2026-10-12 重整欄位架構為 22 欄、CSV 23 欄。四種格式、欄位映射、識別契約、明細關聯契約與目錄只有[輸出欄位](../輸出欄位.md)定義。本企劃不複製欄位清單。
- 維護包只存本機 run 目錄，不公開。公開資料位於 `data/output/`，預定納入 Git。GeoParquet 單一檔 `taiwanlvr.parquet` 由 GitHub release 發布。當前 `.gitignore` 仍忽略整個 `data/`，須由程式／設定工作調整後才能落地目標追蹤方式。
- 正式公告預定由 `config/sources/notice.json` 產生 `data/output/NOTICE.json`。檔案目前不存在，公告內容尚待確認。不得從既有公告推定正式公告已核准。
- `data/output/catalog.json` 登記全部檔案及其格式、範圍、筆數、大小、SHA-256 和路徑。第二類人工查核區和一般待查核表、人工交叉比對清單分開保存。
- 發布流程拆為候選驗證、公開發布、發布後下載核對。候選驗證先通過後才能發布，發布後另核對下載內容及雜湊。維護包重產屬私有維護工作，與公開候選驗證分開。
- 開發在 `C:/Code/taiwan-lvr-geodata` 的 `main` 進行。本地驗收後提交，再推送 `origin/main`。除非擁有者明確要求，不建立副本、階段分支或 PR。
- 安裝和自動測試使用合成資料，不下載真實資料、不使用憑證。真實資料命令另記明確輸入、授權操作、雜湊及結果。相關地址專案的發布或更新不屬本階段。

## 工作流程與依賴

依賴以卡片表為準。候選驗證依賴新版輸出及已核准公告。公開發布須先通過候選驗證並取得該次發布授權。發布後下載核對只針對已發布版本執行。私有維護包驗證及重產不要求先公開發布。TGOS 同址修復可獨立進行，不以新版公開發布為前置條件。
