# C TGOS 交換與採用規則

類別 ii：送出 TGOS，並依結果逐漸修改。修訂日期：2026-10-18。現況與擁有者決定以 [00 主企劃](00-主企劃.md)與[擁有者決定與驗收總表](擁有者決定與驗收總表.md)為準。

## 目的

每天送一批查詢到 TGOS、匯入回傳，並把擁有者已裁定的同址採用規則寫進匯入程式。採用規則不影響送什麼，只影響回傳怎麼判定，而且每次 run 都會以當時規則重新解讀全部回傳，所以可以邊送邊改。每批匯入後檢視拒絕的分類，發現新模式就提規則給擁有者。

## 前置

B 段完成，送查檔已從過渡基線重產。

## 陷阱

- 採用規則只決定座標是否採用，不改 `building_key`、不合併門牌鍵。
- 改了 `lvr_pipeline/` 就使之前 run 的指紋失效，下一次發布前要全量重跑。所以 C-2、C-3 的程式最好在 B 段之後、D 段的程式之前或一起進同一次重跑；累積多個規則一次重跑，不要每條規則跑一次。
- `data/tgos/`：已送出批次的送查檔與回傳不覆寫、不刪除；已取消且從未送出的批次，資料夾必須刪除（2026-10-18 擁有者決定），取消時一併刪除，帳本中的批次與雜湊紀錄不變。
