## Release 說明草稿

以下供擁有者建立 release 時使用，版本名稱由擁有者決定。

> **第一版：全歷史離線定位輸出（截止 2026-10）**
>
> 內政部不動產成交案件實際資訊全歷史 58 個來源批次，買賣、預售屋、租賃三類，2011-01 至 2026-10。每個有座標的門牌一列，共 3,551,724 列，涵蓋 3,548,791 筆交易。座標全部來自離線地址比對；離線定位不到的門牌不在本版，TGOS 回補將在第二版加入。
>
> - `taiwanlvr.parquet`：GeoParquet 1.1.0 單檔，22 欄，1,000,026,444 bytes，SHA-256 `3d5b851b38b465c423a446f73f75376ef58fa86857c08f252ff32780e7237857`。
> - 每月每類別 CSV 23 欄，在 repo 的 `data/output/csv/`，檔案索引與雜湊見 `data/output/catalog.json`（SHA-256 `5a0067ccb056437ebd09ee8483b9c6ba34599d0e23803b4ab213c88482081ba2`）。
> - 欄位說明見 `docs/輸出欄位.md`；多門牌交易的價格不分攤，加總時依 `transaction_id` 去重。
