## 實作內容

**規則 A，拒絕碼。** `lvr_pipeline/tgos/validate.py` 的非數字座標改記 `TGOS coordinate is not numeric`。`lvr_pipeline/results/review.py` 的 `TGOS_REJECTION_CODES` 新增四個對應：座標只有一半、非數字對應 `tgos_coordinate_invalid`，成功列缺 `Response_Address` 對應 `tgos_response_incomplete`，歧義對應 `tgos_village_ambiguous`。新測試 `test_every_recorded_rejection_reason_has_a_review_code` 從原始碼擷取拒絕字串核對對應表；`raise` 移到別處時須跟著改。

**規則 B，跨村里或鄰歧義。** `validate.py` 新增 `_layer_is_ambiguous`，在 `same_door` 通過後、採用座標前執行。匯入時對 `address-result` 全部鍵依門牌簽章建一次查表；只計與查詢已寫層級相容的其他鍵，查詢沒寫的層級出現兩個以上不同值即拒絕。`tgos_village_ambiguous` 加入 `lvr_pipeline/contracts/schemas.py` 的 `EXCEPTION_REASON_CODES`。

**規則 C，軸向。** 不改程式。經緯對調 `(25.03, 121.56)` 與 TWD97 `(302000, 2770000)` 都由範圍檢查拒絕，測試在 `tests/integration/test_r09_2_same_door.py`。

**帳本帶入整理。** 依 10-17 決定 6，保留 `--ledger` 與 `_carry_ledger`；刪除 R09-0 的無鍵查詢處理，範圍為 `tgos/batches.py`、`tgos/__init__.py`、`tgos/validate.py`、`results/review.py`、`storage/parquet.py`、`storage/runs.py`、`contracts/schemas.py`。帳本中有現行規則算不出門牌鍵的查詢時，`prepare-tgos` 拒絕。`_write_state` 的 `extra_inputs` 參數只為綁定無鍵清單而存在，一併刪除。刪除 7 個只測無鍵帶入的測試與 `seeded` 夾具；新增 `test_ledger_query_without_a_key_makes_prepare_fail`。

**路徑。** `prepare-tgos`、`repair-tgos-exchange`、`set-tgos-status`、`import-tgos`、`build-review` 移除 `--work-dir`，必填 `--run-id`，新增 `--runs-root`。`--run-id` 改為 run 目錄名，快照 ID 一律由綁定雜湊產生，同一 run 連續 `prepare` 不會撞名。`lvr_pipeline/pipeline.py` 的 `_tgos_run_dir` 在 run 目錄已有 `manifest.json` 時拒絕，該檔由 `RunStore` 寫入（`storage/runs.py:394-398`）。`test_cli_build_review` 改以 store 的現行指標找快照。
