## 變更內容

- `lvr_pipeline/addresses/identity.py`：刪除舊 `building_key`（原 198-250 行）及只供它使用的 `_NUM_END_RE`、`_FLOOR_RE`、`_YI_TO_ZHI_RE`、`_DASH_ZHI_RE`。`building_key_v2` 改名為 `building_key`，函式本體與 `v2:` 前綴不變。
- `lvr_pipeline/address.py`：`__all__` 只列一次 `building_key`。
- `lvr_pipeline/transactions/normalize.py`：移除 `legacy_building_key` 輸出欄位。
- `lvr_pipeline/contracts/schemas.py`、`address-component.schema.json`、`converted-parquet.json`：移除 `legacy_building_key`。
- `lvr_pipeline/pipeline.py`：run 綁定 `key_version` 改為 `building_key/{NORMALIZATION_VERSION}`。重建前的 run 目錄因綁定不同而無法續用。
- 其餘 8 個程式檔與 2 個 scripts 只改名稱。
- 測試：刪除 `tests/unit/test_address.py` 中 12 個舊演算法測試。`test_p0_contracts.py` 刪除一個斷言舊演算法結果的敘述，並把 `test_legacy_stays_compatible` 改名為 `test_fullwidth_and_tai_variants_share_key`。其餘測試只改名稱。
- `tests/regression/test_old_rule_snapshot_readable.py` 只改名稱。它驗證「舊規則快照仍可讀」，與重建隔離要求相反，留給 R07-6a 處理。
