## 擁有者決定

1. 欄位架構由 35 欄重整為 23 欄。移除 `door_id`、`multi_door`、`door_count_located`、`price_counted`、`land_count`、`building_count`、`parking_count`、`src_batch`、`member_path`、`source_row_number`、`source_serial`，以及 GIS 格式中的 `longitude`、`latitude`。原因是每個值只存一次，不設補救欄位。
2. `transaction_id` 改為可讀自然鍵 `{src_batch}/{member_path}/{source_row_number}`。批次 ZIP 雜湊記在 `catalog.json`。id 只在同一輸出版本內有效。
3. 公開主鍵為 `transaction_id` 加 `door_index`。
4. `address` 改為拆解後的單一門牌文字。`transaction_addresses` 保留原文。
5. 加總規則只有一條：依 `transaction_id` 去重。
6. `編號` 是否存在且唯一不先掃描，由建置時逐檔檢查判定，六項計數寫入 run report 作為 V-10b 證據。
7. 單一門牌圖層維持。兩表方案被提出但未採用。
