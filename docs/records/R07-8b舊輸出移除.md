## 變更

- `run-full` 的輸出階段改用 `write_output`。輸出放在 run 目錄 `output/<output_id>/public/` 與 `release/`。`output_id` 由 converted 與定位狀態的 manifest 雜湊及契約版本算出。
- 輸出階段快照保存 `output.json`，內含每個輸出檔的 SHA-256。重用前重算全部雜湊，不符時中止且不修改目錄。目錄已存在但不是已驗證的重用時拒絕寫入。
- `run-full` 移除 `--notices`。公告處理在 R08 重新加入。
- run report 的 `output` 改為 `output_id`、`public_dir`、`release_dir`、`total_rows`、`file_count`、`parquet_rows`。

## 結論與限制

- 舊輸出路徑已完全移除，`run-full` 只產生新版 22 欄輸出。
- 輸出中途失敗時，run 目錄留下不完整的 `output/<output_id>/`，同一 run 再執行會拒絕。復原方式是使用新 run ID，或由人工移除該目錄。
- 失去的能力：發布、下載核對、維護包與回補目前都沒有命令。這些分別由 R08 與 R10 依新契約重新實作。
- `config/reference/lvr_county_letters.provenance.txt` 已註明來源腳本已刪除。
